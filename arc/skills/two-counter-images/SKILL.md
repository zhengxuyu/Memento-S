# Two Counter-Images

When a thought experiment makes a conclusion feel obvious, construct a counter-image — an equally vivid scenario that supports the opposite conclusion. If both scenarios are equally compelling, the original thought experiment doesn't prove what it seemed to. This is a powerful technique for neutralizing misleading intuition pumps.

## When to Apply
- A thought experiment seems to decisively prove a point
- You have a strong intuitive reaction to a scenario
- Evaluating competing hypotheses that both feel "obvious"

## Procedure
1. Identify the thought experiment and the conclusion it supports
2. Construct a parallel scenario that's equally vivid but supports the opposite conclusion
3. Compare: are both scenarios equally compelling?
4. If yes, the original thought experiment is less decisive than it seemed
5. Look for principled reasons to prefer one scenario over the other

## Example
Intuition pump: "The agent scored by luck, so it doesn't really understand." Counter-image: "A chess master makes an unusual move that looks lucky but reflects deep understanding." Both are vivid — so the original argument from luck alone doesn't settle whether understanding is present.

## Anti-Pattern
Don't use counter-images to create false equivalence. Sometimes one scenario really is more plausible — the tool helps you check, not automatically dismiss.

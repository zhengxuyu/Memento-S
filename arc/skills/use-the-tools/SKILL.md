# Use the Tools, Try Harder

This is the meta-tool. When you're stuck — when a problem resists your first approach — don't just try harder with the same method. Instead, systematically cycle through your toolkit of thinking tools. Each tool offers a different angle, a different way to reframe the problem. The answer is often found not by pushing harder but by pushing differently.

## When to Apply
- You've been stuck on a problem for multiple attempts with no progress
- Your current framing of the problem isn't yielding solutions
- Before declaring something impossible or unsolvable

## Procedure
1. Pause and acknowledge you're stuck
2. List the thinking tools potentially relevant to the current problem
3. Systematically apply each one: reframe the problem, check for hidden assumptions, invert the question, seek analogies, test for sphexishness in your own approach
4. For each tool, spend at least one genuine attempt — don't just check boxes
5. If a tool produces a new angle, pursue it before moving to the next

## Example
An agent can't score on a game after 200 steps. Instead of repeating failed strategies: apply sphexishness (am I looping?), sturgeon's razor (most of my ideas will be bad — generate more), rapoport's rules (what IS working?), jootsing (what rule am I assuming that I could break?). One of these reframings breaks the impasse.

## Anti-Pattern
Don't mechanically run through every tool as a checklist without genuine engagement. The point is to actually think from each tool's perspective, not to perform the appearance of effort.

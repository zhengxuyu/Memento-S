# The Chinese Room

Searle's Chinese Room: a person follows rules to manipulate Chinese symbols without understanding Chinese. Searle argues this shows computers can't understand. Dennett's reply: the *person* doesn't understand, but the whole *system* (person + rules + database) might. Understanding can be a property of the system, not any single component.

## When to Apply
- Arguing that a component's lack of understanding proves the system doesn't understand
- Confusing the understanding of a part with the understanding of the whole
- Evaluating claims that "mere symbol manipulation" can't produce meaning

## Procedure
1. Identify the system and the component being examined
2. Note: the component may not understand, but that doesn't settle whether the system does
3. Ask: does the system as a whole exhibit understanding (appropriate responses, generalization, error correction)?
4. If yes, don't dismiss it just because no single component "gets it"
5. Look for understanding at the right level of analysis

## Example
A single function in the agent doesn't "understand" the game — it just maps inputs to outputs. But the whole agent (perception + memory + hypotheses + planning) might genuinely understand game mechanics. Don't judge the system by examining one subroutine.

## Anti-Pattern
Don't use the "systems reply" to attribute understanding to everything. A thermostat is a system too, but it doesn't understand temperature. The system needs to exhibit genuine hallmarks of understanding.

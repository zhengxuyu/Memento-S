# Reductio ad Absurdum

To test whether a claim is true, assume it is true and follow its implications rigorously. If the implications lead to a contradiction, absurdity, or something known to be false, the original claim must be wrong. This is one of the most powerful tools for eliminating bad hypotheses.

## When to Apply
- A hypothesis seems plausible but you're unsure if it holds universally
- Two competing explanations both seem reasonable
- You suspect a rule or pattern has hidden exceptions
- Someone (or your own reasoning) has made a claim that "feels right" but hasn't been tested

## Procedure
1. State the hypothesis clearly
2. Assume it is true
3. Derive logical consequences — push them as far as they go
4. Check if any consequence contradicts known facts or itself
5. If contradiction found: reject the hypothesis. If no contradiction: it survives (but isn't proven)

## Example
Hypothesis: "The player scores by touching any colored object." If true, then touching walls (also colored) should score — but it doesn't. Therefore, scoring requires something more specific than mere contact with colored objects.

## Anti-Pattern
Don't confuse "leads to a surprising conclusion" with "leads to an absurd conclusion." Surprising results may be true. Only genuine contradictions count as refutations.

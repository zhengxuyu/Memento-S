# Mary the Color Scientist

Mary knows every physical fact about color vision but has never seen color. When she finally sees red, does she learn something new? This tests intuitions about whether objective, third-person descriptions can fully capture a phenomenon or whether something is left out.

## When to Apply
- Someone claims a model or description "captures everything" about a domain
- A debate hinges on whether subjective experience adds information beyond functional description
- You need to distinguish between knowing-how and knowing-that in system design

## Procedure
1. Identify what "complete description" is being claimed
2. Ask: could someone with that description still be surprised by the real thing?
3. If yes, determine whether the surprise reveals a genuine gap or just a different format of the same knowledge
4. Decide whether the "gap" matters for the task at hand or is a philosophical curiosity

## Example
A game-playing agent has a complete symbolic model of a level's mechanics but has never run it. When it finally plays, emergent timing interactions surprise it. Mary's Room asks: was the surprise genuine new information, or just the same facts experienced in a different modality?

## Anti-Pattern
Don't assume the thought experiment settles the qualia debate. It's a pump for intuitions, not a proof. Use it to surface assumptions, not to declare victory.

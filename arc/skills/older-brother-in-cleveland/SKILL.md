# An Older Brother Living in Cleveland

Dennett's method: when someone makes a sweeping claim, test it with a specific, concrete case. "All X are Y" can be demolished by finding one X that isn't Y. Abstract claims feel plausible until you check them against concrete reality.

## When to Apply
- A universal rule has been proposed ("X always causes Y")
- Abstract reasoning has gone on too long without grounding
- You need to test whether a pattern holds generally or only in specific cases
- A hypothesis is based on a few observations and is being generalized

## Procedure
1. State the general claim being made
2. Construct a specific, concrete scenario that the claim must cover
3. Check whether the claim actually holds in that specific case
4. If it fails, the general claim needs qualification or rejection
5. If it holds, try another concrete case — especially an edge case

## Example
Claim: "Moving toward any goal-colored object increases the score." Concrete test: there's a goal-colored object in the corner of the map. Move to it specifically. If the score doesn't change, the general claim is false — location or some other factor matters.

## Anti-Pattern
Don't construct only easy cases that you know will confirm the claim. The value is in constructing *challenging* concrete cases, especially ones at the boundaries of the claim's scope.

# Manifest Image vs. Scientific Image

Wilfrid Sellars' distinction: the *manifest image* is how the world appears to us in everyday experience (colors, purposes, meanings). The *scientific image* is the underlying mechanical reality (wavelengths, causes, computations). Both are useful, but confusing them leads to errors.

## When to Apply
- Surface appearances (what you "see") conflict with measured data
- A folk explanation feels right but doesn't predict outcomes correctly
- You need to move from description ("it looks like X") to mechanism ("X happens because Y")
- Debugging: the manifest image says "it should work" but it doesn't

## Procedure
1. State the manifest image: how does the situation appear at face value?
2. State the scientific image: what are the actual mechanisms at work?
3. Identify where the two images conflict or diverge
4. For prediction and action, rely on the scientific image
5. Use the manifest image for communication and intuition-building only

## Example
Manifest: "The player is trapped in a room." Scientific: "The player occupies cell (58,6) and BFS finds no path to cells outside the 10x10 region because walls block all cardinal directions." The scientific image reveals that maybe diagonal movement or a teleport action exists — the "room" framing may hide escape routes.

## Anti-Pattern
Don't dismiss the manifest image entirely. It provides useful heuristics and intuitions. The error is *only* relying on it when precise mechanisms matter, or confusing how things appear with how things work.

# Cycles

Feedback loops — where output becomes input — are the engine of emergent complexity. Simple rules plus cycles produce surprisingly rich behavior. Autocatalytic cycles in chemistry, predator-prey oscillations in ecology, and reinforcement loops in learning all share this structure.

## When to Apply
- A system's behavior seems more complex than its components warrant
- You observe oscillation, escalation, or self-reinforcing patterns
- Looking for the mechanism behind emergent behavior

## Procedure
1. Identify the components and their interactions
2. Look for loops: does any output feed back as input?
3. Classify the loop: positive (amplifying) or negative (stabilizing)?
4. Trace the cycle to predict behavior: will it escalate, oscillate, or stabilize?
5. Consider whether breaking or modifying the cycle would change the outcome

## Example
An agent moves toward an object, which triggers the object to move away, which causes the agent to pursue further. This positive feedback cycle produces chasing behavior from two simple rules (approach, flee). Recognizing the cycle explains the emergent pattern.

## Anti-Pattern
Don't see cycles everywhere. Not all complex behavior comes from feedback loops — some emerges from one-shot interactions or hierarchical structure.

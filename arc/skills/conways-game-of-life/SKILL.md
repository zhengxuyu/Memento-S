# Conway's Game of Life

Four simple rules on a grid produce gliders, oscillators, and universal computation. The Game of Life demonstrates that determinism does not imply predictability — you can know all the rules and still be unable to shortcut running the simulation.

## When to Apply
- Someone conflates deterministic with predictable or boring
- An argument assumes that knowing the rules means you can skip the execution
- You need to explain how complex behavior emerges from simple components

## Procedure
1. Identify the claim that knowing rules = knowing outcomes
2. Point out that Game of Life rules are trivially simple yet computationally irreducible
3. Note: the only way to know what step 1000 looks like is to simulate all 1000 steps
4. Apply this insight: the system in question may be deterministic but still genuinely surprising

## Example
Someone says "the game is deterministic, so the agent should be able to predict what happens next." Conway's Game of Life shows that determinism doesn't grant predictive shortcuts — the agent may still need to simulate or explore.

## Anti-Pattern
Don't imply emergence is mystical or inexplicable. The point is computational irreducibility, not mystery.

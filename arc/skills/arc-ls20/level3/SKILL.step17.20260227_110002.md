# Game Mechanics
- **Player Avatar**: A 5x5 block (top 2 rows color 12, bottom 3 rows color 9).
- **Movement**: ACTION1-4 moves exactly 5 cells. Costs 1 action. (ACTION1=UP, ACTION2=DOWN, ACTION3=LEFT, ACTION4=RIGHT).
- **Timer / Action Limit**: Color 11 bar at the bottom. Depletes exactly 2 blocks (e.g. at row 61,62) per action.
- **TIME EXTENDERS**: Stepping perfectly over 3x3 U-shapes made of color 11 ADDS to your timer (restores ~13 actions). Always collect them if they are near your path!

# Level 3 Route Info
- Start: (45,9)
- Current Position: (5,34)
- Button: Covers (11-13, 50-52). Target player pos: (10,49).

# Strategy to Win 
1. Strict 5x5 alignments avoiding obstacle walls (color 5).
2. Continue Traversing RIGHT (ACTION4) towards X=49. 
3. Move DOWN (ACTION2) to trigger the button at (10,49).
4. Navigate path to goal. Keep an eye out for more color 11 extenders.

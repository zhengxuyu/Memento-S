# Game Mechanics
- **Player Avatar**: A 5x5 block (top 2 rows color 12, bottom 3 rows color 9).
- **Movement**: ACTION1-4 moves exactly 5 cells. Costs 1 action.
- **Timer / Action Limit**: Color 11 bar at the bottom.
- **TIME EXTENDERS**: Stepping perfectly over 3x3 U-shapes made of color 11 ADDS to your timer (restores ~13 actions). They are often placed in 1-block dead ends, meaning you must collect and immediately backtrack. Always collect them if they are near your path!

# Level 3 Route Info
- Start: (45,9)
- Collect Time Extender: (5,34) -> Dead end! Must go left.
- Current Position: (5,34)
- Button target: (10,49).

# Strategy to Win 
1. Strict 5x5 alignments avoiding obstacle walls (color 5).
2. Note that stepping into walls ignores movement and wastes an action.
3. If at (5,34), move LEFT (ACTION3) back to main path at (5,29).
4. Find path downwards/rightwards to get to (10,49).

# Inert Historical Facts

Some facts about the past are true but causally disconnected from anything that matters going forward. If no current state carries information about a past event, that event is inert — real but irrelevant to decisions. This matters for questions about identity, responsibility, and design.

## When to Apply
- An argument depends on a historical fact that left no trace in the current state
- Someone insists a past event matters even though nothing in the present reflects it
- Evaluating whether an agent's training history should affect how we treat its current behavior

## Procedure
1. Identify the historical fact being invoked
2. Ask: does any current state carry information about this fact?
3. If no causal trace exists in the present, the fact is inert for forward-looking purposes
4. Decide whether the argument can survive without the inert fact

## Example
Two agents are functionally identical but were trained with different random seeds. Someone argues they should be evaluated differently because of their training histories. Inert historical facts: if no behavioral difference exists, the different histories are inert.

## Anti-Pattern
Don't use this to dismiss all history as irrelevant. Many historical facts leave real causal traces. Only apply when the fact genuinely left no mark on current state.

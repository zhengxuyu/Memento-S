# The Teleclone Fall

If a teleporter destroys you and builds an exact copy at the destination, does "you" arrive? If two copies are made, which one is you? This thought experiment reveals that our intuitions about personal identity often rely on hidden assumptions about continuity and uniqueness.

## When to Apply
- An argument assumes personal identity is simple or indivisible
- Someone conflates psychological continuity with metaphysical identity
- A design treats "the same agent" as an unambiguous concept (e.g., after copying state)

## Procedure
1. Identify the entity whose identity is being assumed stable
2. Imagine duplicating that entity perfectly — which copy is "the real one"?
3. Notice what criterion you reach for (continuity, memory, spatial location, causal chain)
4. Ask whether that criterion actually does the work the argument needs

## Example
An agent claims "I learned X in the last episode" after its weights are copied to a new instance. The teleclone test asks: if two copies exist, which one "learned" X? This exposes that identity here is really about causal-informational continuity, not some metaphysical self.

## Anti-Pattern
Don't use this to generate idle sci-fi puzzles. The point is to clarify which identity criterion is doing real work in a concrete argument.

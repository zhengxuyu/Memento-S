# Three Species of Goulding

Dennett identifies three rhetorical moves (named after patterns in Stephen Jay Gould's writing) that look like good arguments but aren't:

1. **Rathering**: Presenting a false dichotomy — "it's either X or Y" when other options exist
2. **Piling On**: Overwhelming with volume of weak arguments instead of one strong one
3. **Gould Two-Step**: Alternating between a strong-but-trivial claim and a bold-but-unsupported claim

## When to Apply
- Evaluating an argument that feels persuasive but suspiciously so
- Your own reasoning presents only two options — are there more?
- A conclusion seems supported by many points, but each is weak individually
- A claim seems to shift between modest and bold versions

## Procedure
1. Check for Rathering: Are only two options presented? List alternatives that were excluded
2. Check for Piling On: Would any single argument be convincing alone? If not, quantity doesn't help
3. Check for Two-Step: Is the claim consistent? Or does it retreat to a weaker version when challenged?
4. If any pattern is detected, restructure the argument without the fallacy

## Example
Reasoning: "Either the goal is reached by moving UP or the game is unsolvable." This is Rathering — it ignores possibilities like needing to interact with objects, pressing specific keys, or reaching the goal from a particular direction. Listing more options breaks the false dichotomy.

## Anti-Pattern
Don't label every dichotomy as Rathering — some choices genuinely are binary. Only flag it when legitimate alternatives are being excluded without justification.

# Boom Crutch

A boom crutch is a thought experiment that seems to deliver a decisive "boom" — a knockout argument — but actually relies on a hidden crutch: an unexamined assumption, a loaded framing, or a misleading analogy. The "boom" is louder than the argument warrants.

## When to Apply
- A thought experiment feels like it settles a debate conclusively
- The force of an argument comes from vivid imagery rather than logical structure
- You suspect the scenario smuggles in the conclusion via its framing

## Procedure
1. Identify the thought experiment and its intended conclusion
2. Separate the vivid, persuasive imagery from the logical structure
3. Look for hidden assumptions or loaded framings that do the real work
4. Test: does the conclusion still follow if you modify the thought experiment's inessential details?

## Example
"Imagine an agent locked in a box with no sensors — clearly it can't learn anything, so embodiment is necessary for learning." Boom crutch: the "no sensors" framing smuggles in the conclusion. The real question is whether learning requires specific kinds of sensor input, not whether it requires any input at all.

## Anti-Pattern
Don't dismiss all thought experiments as boom crutches. Many are genuinely illuminating. This tool targets specifically those where the persuasive force exceeds the logical warrant.

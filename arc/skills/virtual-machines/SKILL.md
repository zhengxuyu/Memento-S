# Virtual Machines

A virtual machine is a software-defined layer that behaves as if it were a distinct machine, even though it runs on underlying hardware. The mind can be understood as a virtual machine running on the brain. Each layer has its own vocabulary, rules, and causal powers — you don't need to talk about transistors to debug Python.

## When to Apply
- Explaining how mental phenomena relate to neural activity
- Justifying why higher-level descriptions are legitimate and not "merely" metaphorical
- Analyzing systems with multiple layers of abstraction

## Procedure
1. Identify the substrate layer (hardware, neurons, physics)
2. Identify the virtual machine layer (software, mind, social norms)
3. Confirm the higher layer has its own consistent patterns and causal regularities
4. Explain behavior at the appropriate level — don't always reduce to the substrate
5. Note where cross-level interactions matter (bugs, brain damage, etc.)

## Example
A word processor is a virtual machine running on an OS running on hardware. "Deleting a paragraph" is a real causal event at the word-processor level. You don't need to describe electron flows to explain it. Similarly, "deciding to go left" is a real event at the mind level, even though neurons implement it.

## Anti-Pattern
Don't treat virtual machines as ghostly extras floating above the physical. They are the physical, described at a different grain. Dualism is not the point.
